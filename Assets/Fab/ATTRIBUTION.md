# Атрибуция и источники ассетов (Assets/Fab)

Все пакеты приобретены/получены пользователем проекта через Fab (Epic Games)
и переданы для интеграции в «Белёк: Вечный Прибой». Используются в
соответствии с лицензией Fab EULA владельца аккаунта.

| Пакет | Источник | Использование в игре |
|---|---|---|
| Fantastic Dungeon Pack (URP, Unity 6) | Fab — Tidal Flask | Реалм 2 «Затонувший Форт» (v0.6.0), пропсы |
| Corals | Fab — (Corals pack) | Реалм 1 «Ледяные Сады» |
| Meadows & Mountains I | Fab — Mountains/Meadows | Хаб «Тёплая Бухта», реалм 3 «Тундра Ветров» |
| Low Poly Nature (VertexRage) | Fab — VertexRageStudio | Растительность хаба и Тихих Лес |
| Forest Animals Pack (ANIMALS FULL PACK) | Fab | НПС-фауна (волк/лиса/заяц/олень/медведь/кабан) |
| Stone Golem | Fab | Босс «Хранитель Шторма» (реалм 5) |
| SciFi Characters MegaPack Vol3 — Megaspikan | Fab — Protofactor | «Пузыри шторма» (личинки) в реалме 5 |
| Robot 3 | Fab | БИП-7 — компаньон |
| Radical Robots Mike | Fab — Tacko3D | Роботы форта (v0.6.0) |

Правила (DesignDocs/03):
- материалы приводятся к URP скриптом FabMaterialFixer при каждой сборке;
- текстуры >2048px ужимаются на этапе импорта (сделано при распаковке);
- ассет без игровой роли в сцену не включается;
- контент пакетов не перераспространяется за пределами этого приватного репозитория
  и билдов игры для владельца.
