# 06. Озвучка персонажей: Silero TTS пайплайн (v0.5.0)

> Требование ТЗ: «озвучить всех персонажей (лёгкая TTS-модель с хорошим
> русским), диалоги живые, голос всегда одинаковый». Решение: **Silero TTS**
> (v4/v5, CPU-friendly, MIT) — оффлайн-генерация на этапе разработки,
> WAV-файлы коммитятся в `Assets/Audio/Voices/`. В рантайме — только
> воспроизведение: нулевые требования к CPU ребёнка.

---

## 1. Почему Silero и почему прекоммит-генерация

- Качество русского — лучшее среди лёгких моделей (v3_fn/v4_ru, 61 голос);
- Работает на CPU за секунды → генерим на машине разработки (эта среда),
  в билд идут готовые WAV/OGG — **модель не попадает в игру** (экономия 60+ MB);
- Детерминированность: сид фиксируется → перегенерация даёт тот же голос;
- Лицензия MIT — безопасно для коммерции.

## 2. Пайплайн (скрипты в `Tools/tts/`)

```
Tools/tts/
  voices.yaml          # контракт: персонаж → спикер, скорость, питч (DesignDocs/02)
  generate.py          # читает dialogues.csv → синтез → Assets/Audio/Voices/<key>.wav
  dialogues.csv        # id, npcId, text, variantIndex
  requirements.txt     # torch-cpu, silero (pip)
```

Процесс:
1. `dialogues.csv` — единый источник текстов (та же таблица, что идёт в
   LocalizationManager: ключи `npc.bip7.line01` и т.д.);
2. `generate.py`: batch-синтез → нормализация loudness (-16 LUFS) →
   обрезка тишины → `Assets/Audio/Voices/<npcId>_<key>_<variant>.ogg`
   (Vorbis, quality 0.42 — ~35 KB/сек речи);
3. Генерация `Assets/Data/Loc/voice_manifest.csv`: ключ → клип → длительность;
4. CI-гейт: каждый ключ `DialogueLine` из сцены обязан иметь клип или явный
   флаг `muted` (иначе — предупреждение в билд-логе).

## 3. Рантайм: DialogueDirector (v0.5.0)

```
DialogueDirector (singleton, ~200 строк):
  Show(npcId, locKey, variants) →
    1) субтитры в HUD (Canvas, крупные, тир-5 режим — ≤8 слов на строке);
    2) AudioSource.PlayOneShot(clip) — 2D-звук (диалоги не позиционируем);
    3) событие OnDialogueStart/End (мусор-безопасно, без аллокаций в цикле);
    4) пока реплика играет — InputRouter.DialoqueBusy (таймеры мира замедлены ×0.3).
```

- Голос закреплён в `VoiceCast` (Data/Loc/voices.yaml → ScriptableObject):
  персонаж без записи в VoiceCast не получает реплик — защита от «чужих» голосов.
- Вариативность: 2–3 варианта реплики, рандом без повтора подряд (как в NpcFriend).

## 4. Качество «живости» (без нейро-трюков)

- Реплики пишутся под голос (Марта тянет «э-эх», Клод тараторит);
- Паузы между фразами 350–700 мс (естественный ритм речи);
- Фоновый лёгкий «руммбл» океана в подложке голоса (−28 dB) — связность мира;
- Никакого реверба в диалогах — сухой голос = интимность разговора.

## 5. Бюджеты

- ~120 реплик на v0.5.0 → ~14 минут речи → ~30 MB OGG — приемлемо;
- Прогрев: генерация всей таблицы ≈ 20–40 мин CPU — разово в Tools.

## 6. План внедрения

1. v0.5.0: VoiceCast + DialogueDirector + озвучка хаба (Марта, Клод, БИП-7 —
   ~40 реплик) и «приветствий» реалма 1;
2. v0.6.0: реплики форта (Цыпа, роботы) ~30;
3. v0.8.0: Хранитель (низкий питч) ~15;
4. v0.9.0: Дневники Белека начитка ~8×40 сек.
