# 03. Интеграция ассетов Fab: пакет → реалм, шейдеры, оптимизация

> Правило: **каждый ассет из пакета должен получить дом** (реалм, роль,
> скрипт-поведение). Ассет без роли не грузим — экономим память (целевые
> GPU: от Vega 56 до M1; дети играют на «семейных» машинах).

## 2. Проблема шейдеров и наше решение

Пакеты из разных эпох RP: Built-in (Standard), URP-версии, ShaderGraph.
В URP-проекте Built-in материалы → розовые. План (уже отработан в v0.3.x
на рыбе/косатке — MaterialBuilder):

1. **Editor-скрипт `FabMaterialFixer`** (запуск в CI перед билдом,
   idempotent): обходит `Assets/Fab/**/*.mat`, заменяет шейдер на
   `Universal Render Pipeline/Lit` если текущий шейдер — `Standard`,
   `Legacy/*` или missing; переносит _BaseMap/_MainTex, _Color, _BumpMap.
2. **Runtime-fallback** в `FabPinkGuard` (на всякий случай, как v0.3.1):
   при `Shader.PropertyToID` ошибке — горячая замена на URP/Lit.
3. Текстурные импорты: все PNG/TGA — sRGB off для Normal/Mask (мета из
   пакетов в основном корректна; FabMaterialFixer правит
   `TextureImporter`-типы по имени `_N`/`_Normal`/`_Mask`).

## 3. Производительность (важно: дети, старые GPU)

- **Даунскейл текстур** сделан на этапе импорта пакетов: всё >12MB → ≤2048px
  (76 текстур, −2 GB). Дальше Unity-импорт: maxSize 1024 для пропсов,
  2048 только для героев (голем, роботы, животные).
- **GPU Instancing** включён на всех материалах пакетов (урок v0.3.1:
  рыбные школы не рисовались без enableInstancing).
- **LOD:** кораллы/растительность — LOD Group от префабов пакетов; где нет —
  дешёвый `FabAutoLOD` (2 уровня, cull 60%).
- **Batching:** статические реальные миры — Static Batching на билд-сцене;
  океан (процедурный) остаётся динамическим.
- **Бюджеты кадра:** ≤ 250 draw calls на реалм, ≤ 60 fps на M1/Vega.

## 4. Анимации животных → арктические роли (маппинг)

| FBX-контроллер пакета | Арктическая роль | Поведение (скрипт) |
|---|---|---|
| Wolf_Controller | Полярный волк Северглаз | NpcBrain: «сторож» — ходит по кругу, диалог-точка |
| Fox_Controller | Песец Фырка | Racer: гонки по сплайнам, 3 медали |
| Rabbit_Controller | Заяц-норник | Jumper: прыгает по льдинам, мини-игра «повтори ритм» |
| DeerDoe/Stag_Controller | Северные олени | Wanderer: пасутся, пугливы (подходи медленно) |
| Bear_Controller | Медведь Потап | SweetTooth: сидит у дупла, квест «ягоды» |
| Boar_Controller | Кабан-бродяга | Grumpy: перегораживает тропу, отвлекается на жёлудь |

Все животные: `FabNpc` ( prefab + контроллер пакета) + наш `NpcBrain`
поверх (Raycast-взаимодействие E, DialogueLine из таблицы, TTS-ключ).

## 5. Реестр ассетов (Asset Ledger) — живой документ

Ведём `DesignDocs/AssetLedger.md`: каждая крупная группа пакетов → где
использована. Обновляется при каждом PR с ассетами. Это защита от
«скачали 3 GB и забыли».

## 6. Пакет «Корабль с элементами» (ожидается)

Когда пользователь дольёт: осматриваем, определяем роль по содержимому.
Кандидаты: «Корабль-Ледокол Деда Прибоя» (хаб, плот-апгрейд) или
«Затонувший корабль» (Окрытое Море, подлёдная достопримечательность).
Вписываем в реалм 6 с самопроверкой по чек-листу анти-абсурда.
